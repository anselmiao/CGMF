# Conditional multivariate G2 history analysis

The script `tools/analysis/g2ConditionalHistoryAnalysis.py` analyzes complete LF/HF pairs from `cgmf.g2.mixed-history.v1` JSONL.

## What is tested

For each fragment it constructs a 14-coordinate event-level history summary:

- neutron multiplicity;
- Lab and CM neutron energy mean, spread, maximum, total, first and last;
- neutron direction cosine moments relative to the pre-fragment momentum direction;
- gamma multiplicity and total CM gamma energy;
- internal-conversion multiplicity;
- count of transitions with valid timestamps.

A fragment with zero neutrons is retained with zero-valued neutron coordinates; it is not silently discarded.

The omnibus statistic is the squared Frobenius norm of the within-stratum centered LF/HF cross-covariance matrix after feature-wise scale normalization. The null distribution is generated by permuting whole HF event feature vectors within each stratum. This avoids neutron-level shuffling and preserves correlations among features of a fragment's own history.

## Conditioning tiers

Default strata use exact LF/HF A and Z, plus separately binned LF and HF initial excitation energies. Use `--include-spin-parity` to add exact stored spin and parity indices for both fragments. Run multiple excitation bin widths (default 1, 2, and 4 MeV) to expose the bias/variance and overlap tradeoff.

A narrower bin can reduce confounding from initial-state differences but produce many singleton strata and low effective sample size. A wider bin increases exchangeability counts but leaves more residual variation in the conditioned state. Always report eligible events, eligible strata, and singleton strata with the p-value.

## Example

```bash
python3 tools/analysis/g2ConditionalHistoryAnalysis.py \
  path/to/mixed-history.jsonl \
  --output results/conditional-history.json \
  --excitation-bins-MeV 1,2,4 \
  --permutations 5000 \
  --seed 20261119
```

Add the spin/parity sensitivity tier:

```bash
python3 tools/analysis/g2ConditionalHistoryAnalysis.py \
  path/to/mixed-history.jsonl \
  --output results/conditional-history-spin-parity.json \
  --excitation-bins-MeV 1,2,4 \
  --permutations 5000 \
  --seed 20261119 \
  --include-spin-parity
```

## Interpretation boundary

A small permutation p-value means the simulated LF/HF history summaries retain association under the specific coarsened conditioning and exchangeability assumptions. It does not establish direct cross-fragment interaction. Shared causes not represented in the sidecar (e.g. explicit event TKE/TXE, scission configuration, angular-momentum coupling, and other latent initial conditions) remain possible explanations.

The summaries retain more than a single mean but are not a complete path-distribution comparison. The detector response is not applied. This is a CGMF simulation diagnostic, not an experimental fit and not a proof of a 气论 mechanism.
